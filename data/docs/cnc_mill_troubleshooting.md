# CNC Mill M-200 Troubleshooting Guide

Fictional sample document for demonstration only.

## Daily checks before starting

Check the coolant level and top it up if it is below the MIN mark. Clear chips from the table and the tool carousel. Confirm the way-lube reservoir is full. Run the warm-up program for five minutes before cutting any parts.

## Error E101: Spindle overheat

Error E101 means the spindle temperature is too high. Stop the program and let the machine idle for 15 minutes. Check that the coolant level is above the MIN mark and that the coolant filter is not clogged. Clean the filter if it is dirty. If E101 appears again after cleaning, do not keep running the machine. Tag it out and call maintenance.

## Error E204: Tool change failure

Error E204 means the tool changer could not complete a tool change. Open the door and check that the tool holder is seated correctly. Clear any chips from the tool carousel pockets. Press RESET, then home all axes before restarting the program. If the tool changer fails twice in a row, report it to maintenance because the clamp may be worn.

## Error E310: Axis servo alarm

Error E310 means an axis servo has faulted, often after a collision or an overload. Check the table, vise and tool for signs of a crash. Power-cycle the machine, wait 30 seconds, and home all axes. If the alarm returns, record which axis (X, Y or Z) faulted and call maintenance.

## Chatter and vibration

If the machine chatters during cutting, reduce the feed rate by 10 to 15 percent first. Check the tool for wear, confirm the workpiece is clamped firmly, and make sure the tool stick-out is as short as possible. Replace the tool if the cutting edge is chipped or rounded.
