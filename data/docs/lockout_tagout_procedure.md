# Lockout/Tagout (LOTO) Procedure

Fictional sample document for demonstration only.

## Purpose

Lockout/tagout makes sure a machine cannot start or release stored energy while someone is cleaning, repairing or adjusting it. Follow it every time you work inside the danger zone of a machine.

## Steps to lock out a machine

1. Notify all affected operators and your supervisor that the machine will be shut down.
2. Shut the machine down using its normal stop procedure.
3. Isolate every energy source: electrical, pneumatic, hydraulic and gravity.
4. Apply your personal lock and tag to each energy isolation point. Each worker uses their own lock and keeps the only key.
5. Release or restrain stored energy. Bleed air and hydraulic pressure, discharge capacitors and block any parts that could fall.
6. Verify zero energy. Try to start the machine using the normal start controls. The machine must not start. Then return the controls to the OFF position.

Only after step 6 is complete may work begin.

## Removing a lock

Only the person who applied a lock may remove it. Before removing it, check that tools are cleared away, guards are back in place and everyone is clear of the machine. Tell affected operators before restarting.

If the worker who applied a lock has left the site and cannot be reached, the lock may only be removed by the shift supervisor after confirming the worker has left and the machine is safe. The supervisor must inform the worker before their next shift.

## Group lockout

When several people work on the same machine, each person applies their own lock to the group lockout box. The machine may only be restarted when every lock has been removed.
