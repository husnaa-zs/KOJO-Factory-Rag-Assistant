# Packaging Line 3 Changeover SOP

Fictional sample document for demonstration only.

## Goal

A changeover from one product format to another on Line 3 should take no more than 45 minutes. Record the actual start and end time on the changeover sheet.

## Steps

1. Run-out: let the current product run out completely. Remove all remaining product and packaging materials of the old format from the line.
2. Clean: clean the filler, conveyor and sealing jaws according to the cleaning checklist. Allergen changeovers require a full wash-down and a signed cleaning verification.
3. Change format parts: fit the correct guide rails, filler nozzles and sealing jaws for the new format. Use the format part list taped to the control panel.
4. Adjust the label applicator: load the new labels, check the label position and the date code against the work order.
5. Metal detector check: test the metal detector with the ferrous, non-ferrous and stainless test wands. The detector must reject all three before production starts.
6. First-article check: run a small batch and inspect the first five packs for fill weight, seal quality and label accuracy.
7. Sign-off: the line leader and a quality inspector both sign the changeover sheet before full production begins.

## If the first-article check fails

Stop the line, correct the problem and repeat the first-article check. Do not start full production until the first five packs pass.
